# 川崎

50歳の文系営業職です。

AIにコードを書かせながら、日記・写真・街歩きなど、自分の生活に欲しい小さな道具を作っています。プログラミングを本職にしたことはありません。作って、使って、うまくいかなくて、また直す。その過程を作品として公開しています。

## Projects

- [Five Years Ago Today](https://github.com/tsuyopon76-hub/five-years-ago-today-public) — 5年前の同じ日付の日記、写真、位置履歴を一画面で振り返るローカルアプリ。
- [AI Walking Guide](https://github.com/tsuyopon76-hub/ai-walking-guide) — 坂、旧道、谷戸、水路、石碑など、いつもの街を少し違って歩くためのガイド。

## How I build

1. 生活の中の小さな不便や好奇心を言葉にする。
2. AIにコードを書かせ、実際に動かす。
3. 使ってみて、違うところを具体的に伝える。
4. 個人情報を分離し、架空サンプルで公開できる形に整える。

公開リポジトリのサンプルデータは架空データです。AIの専門家を名乗るのではなく、普通の会社員がAIを道具として使い、どこまで自分の道具を作れるかを記録しています。
